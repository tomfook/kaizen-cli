## 1. データ前処理の落とし穴

### 1.1 ゼロ値データの混入

**教訓**: 非稼働・非営業のゼロ値を含めた集計は、平均値を大幅に歪める

**典型的な失敗パターン**:
- 営業時間外や休業日（指標=0）を含めて平均値を計算
- データの大部分が0値の場合、平均値が実態と乖離する
- **結論が逆転する致命的な誤り**になりうる

**なぜ危険か**:
- ゼロ値の混入割合が時期によって異なると、時期間比較が無意味になる
- 「指標の平均」のつもりが「稼働率」を測っていたことになる

**対策**:
1. データの0値割合を確認する
2. 0の意味を判断する（「未発生」なのか「非稼働」なのか）
3. 非稼働のゼロは除外してから集計する

### 1.2 データカラムの正確な理解

**教訓**: カラムの意味を初期段階で必ず確認すること

**典型的な失敗パターン**:
- 似た名前のカラムを取り違える（例: capacity vs actual, gross vs net）
- カラム定義を確認せずに推測で進める
- **影響**: 全分析・グラフ・レポートの全面やり直し

**対策**:
1. 分析開始時に主要カラムのサンプルデータを表示・確認
2. 似た名前のカラムは特に注意
3. 用語の定義をドキュメントに明記
4. 単位（円/千円、人/千人、%/割合）を明示的に記載

### 1.3 データ型の事前確認

**教訓**: データの型を事前確認し、暗黙の型変換による誤りを防ぐ

**よくある問題**:

| 問題 | 原因 | 対策 |
|-----|------|------|
| フォーマット済み列に再フォーマット適用 | 文字列の`"52.6%"`に数値変換 | `str()`/`dtypes`で事前確認 |
| Excel読み込み時に列がNAになる | 先頭行の空欄で型推論が誤る | `col_types="text"`で読み込み後変換 |
| 同名列でmerge/joinエラー | Excelに同名カラムが複数存在 | 列名の重複チェック→リネーム |

### 1.4 順序付きカテゴリの指定

**教訓**: 順序に意味があるカテゴリ変数は、順序を明示指定しないとアルファベット順になる

**例**:
- 誤: 「10以上, 1のみ, 2-4, 5-9」（アルファベット順）
- 正: 「1のみ, 2-4, 5-9, 10以上」（論理的順序）

## 2. 統計分析の注意点

### 2.1 相関分析の落とし穴

**教訓**: 高い相関係数 ≠ 因果関係。完全相関は同一指標の可能性を疑う。

**チェックポイント**:
1. 相関係数が0.9以上 → 多重共線性を疑う
2. 1.000に近い → 同じことを2つの指標で測っている可能性を検証
3. 「なぜその相関があるのか？」を論理的に説明できるか確認
4. 第三の変数による疑似相関を検討

```r
# 完全相関の検証: 一方が他方の線形変換か確認
cor(df$metric_a, df$metric_b)
summary(lm(metric_b ~ metric_a, data = df))
```

### 2.2 残差分析の重要性

**教訓**: 絶対値ランキングだけでなく、期待値との差（残差）で評価すると別の洞察が得られる

**活用場面**:
- リソース制約下でのパフォーマンス評価
- ベストプラクティスの特定（残差がプラスの対象）
- 改善余地の発見（残差がマイナスの対象）

```r
model <- lm(目的変数 ~ 説明変数, data = df)
df <- df %>%
  mutate(
    predicted = predict(model, .),
    residual = 目的変数 - predicted
  )
df %>% arrange(desc(residual))
```

### 2.3 分析期間の左端効果（YoY分析）

**教訓**: YoY比較の開始月付近で見える傾向は、期間選択によるアーティファクトの可能性がある

**典型的な誤り**:
- 2年間でYoY分析 → 「開始付近は好調」と結論
- 実際は長期トレンドの末尾を拾っていただけ

**対策**:
1. 期間の端（特に左端）に見える傾向は、さらに遡ったデータで検証
2. 可能なら全期間で長期トレンドを確認してからYoY分析
3. 「特定の季節だけ好調/不調」が期間選択のアーティファクトでないか疑う

## 3. データ集計と計算パターン

### 3.1 セグメント別指標の分子・分母の整合性

**教訓**: セグメント別の率・比率を計算する際、分子と分母の両方をセグメント別にする

**原則**: 分子と分母を同じセグメントで揃える

- ❌ 分母は全体、分子だけセグメント別
- ✅ 分子も分母もセグメント別で統一

**チェックポイント**:
1. 結合キーにセグメント列を含めているか
2. 分子と分母が同じセグメントのデータか
3. セグメント構成比の変動が全体指標を歪めていないか

### 3.2 ベースラインの安定性検証

**教訓**: 目標設定のベースラインは複数期間で検証すること

**変動係数（CV）による安定性評価**:
- CV < 5%: 非常に安定
- CV < 10%: 安定
- CV >= 15%: 変動が大きい（要注意）

```r
monthly_data %>%
  summarise(
    mean_val = mean(metric),
    cv = (sd(metric) / mean(metric)) * 100
  )
```

### 3.3 サンプルサイズと評価期間

**教訓**: サンプル数が少ないセグメントは変動が大きく、適切な評価期間の選択が重要

**CVによる評価期間の目安**:
- CV < 15%: 日次評価可能
- CV 15-30%: 週次評価推奨
- CV > 30%: 月次評価推奨

**分析設計への反映**:
1. 分析開始前に各セグメントのサンプル数とCVを確認
2. 少数サンプルセグメントは補助的な参考値として使用
3. 主要結論は大サンプルセグメントで判断
4. レポートでサンプル数とCVを明記（透明性のため）

## 4. 可視化の落とし穴

### 4.1 グラフ種類の選択

**教訓**: 見せたい内容に応じて適切なグラフ種類を選ぶ

| 見せたい内容 | 推奨グラフ | 不向き |
|-------------|-----------|--------|
| 構成比 | 積み上げ棒 | 折れ線 |
| 変動パターンの比較 | 折れ線（複数本重ね） | 積み上げ棒 |
| 差分・インパクト | 横棒グラフ | 円グラフ |
| 2変数の関係 | 散布図 | 棒グラフ |

### 4.2 箱ひげ図が不適切なケース

**教訓**: データが極端に偏っている場合、箱ひげ図は意味をなさない

**判断基準**:

| 状況 | 箱ひげ図の適否 | 代替 |
|------|---------------|------|
| 中央値が0または極端に偏る | 不適切 | 割合・率の棒グラフ |
| IQRが極端に小さい | 不適切 | ヒストグラム、密度プロット |
| 正規分布に近い | 適切 | - |
